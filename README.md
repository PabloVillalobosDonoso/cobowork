## ⚙️ Instrucciones de ejecución

Para ejecutar correctamente el proyecto, debes seguir las instrucciones indicadas en los README de cada carpeta:

- 📁 `/frontend`
- 📁 `/backend`

Cada uno contiene los pasos necesarios para:

- Instalar dependencias
- Configurar variables de entorno
- Ejecutar el proyecto
- Levantar servidores
- Conectar frontend y backend
